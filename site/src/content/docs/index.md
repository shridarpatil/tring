[Tring](https://github.com/shridarpatil/tring) is an open-source, API-first voice platform: browser calling, phone trunks, IVR flows, agent routing, recording and call records, self-hosted with two Go binaries, Postgres and Redis.

These docs cover setup guides for self-hosting.

## Guides

- [WhatsApp calls over SIP (inbound)](/tring/guides/whatsapp-sip/): let WhatsApp users call your business number and reach the same IVR flows and agents as phone callers.
