## What is Tring?

Tring is an open-source, API-first voice platform. Drop a `<script>` tag and a `<button>` into your app, and your agents make and take real phone calls in the browser. Bring your own trunk (Exotel, Airtel, Jio, Tata, or any SIP carrier), and Tring handles the API, browser SDK, IVR, agent routing, recording and call webhooks.

It is multi-tenant, India-first, and self-hosted with the same binaries you'd run as a hosted service. Licensed under Apache 2.0.

## How it fits together

Tring is two Go binaries, one Postgres and one Redis, plus FreeSWITCH as a private edge to the phone network.

| Service | Role |
|---|---|
| `tring-api` (`:8085`) | REST API, admin console, browser SDK bundles |
| `tring-gateway` (`:8087`) | The media plane and the "brain": IVR, agent routing, recording, call records |
| `tring-fs` | FreeSWITCH: the SIP edge to your carrier trunks (and WhatsApp) |
| `tring-db`, `tring-redis` | Postgres for data, Redis for agent presence and call tokens |

Every call, whether from a browser, a phone or WhatsApp, becomes a room on one media plane, so IVR, transfers, recording and call records work the same way regardless of where the call came from.
