Local demo setup

This page has zero JS of its own. The only voice-related bit is a single <script src="/sdk/agent.js"> tag injected after you paste a JWT below. In a real CRM, your backend mints and templates the JWT before the page is rendered.

Mint a JWT against the running Tring API. AUTH can be a console login (below) or a tenant API key — issue a tk_live_… key under /admin/ → API keys and skip step 1 (AUTH=tk_live_…). Both authenticate the same /v1 routes.

# 1. get an AUTH token — EITHER a tenant API key (recommended) …
AUTH=tk_live_…    # from /admin/ → API keys
#    … OR a console login with the bootstrap admin user:
AUTH=$(curl -sS -X POST http://localhost:8085/v1/console/login \
  -H "Content-Type: application/json" \
  -d '{"email":"admin@tring.local","password":"tring_dev_change_me"}' \
  | jq -r .token)

# 2. pick an agent (or create one first via /admin/ → Agents)
AGENT=$(curl -sS -H "Authorization: Bearer $AUTH" \
  http://localhost:8085/v1/agents | jq -r '.[0].id')

# 3. mint a short-lived SDK token for that agent — paste it below
curl -sS -H "Authorization: Bearer $AUTH" \
  http://localhost:8085/v1/agents/$AGENT/token | jq -r .token

The agent connects to the media gateway over raw WebRTC — no SIP in the browser, FreeSWITCH stays private. The gateway URL is required; point it at your running gateway.

What's happening under the hood

  • Each Call button has data-tring-agent-call data-to="…" — that's the whole integration on the HTML side.
  • Media gateway (ADR-001): agent.js opens one WebSocket to the media gateway (/agent/ws) with the JWT for presence + incoming-call signaling, then peers over raw WebRTC. No SIP in the browser; FreeSWITCH stays private. Requires the gateway running and agent_transport=gateway on the server.
  • Clicking Call posts to /v1/sdk/calls. Tring tells FreeSWITCH to ring the agent's browser; on answer, the call bridges to the destination via the configured trunk (loopback in dev, Exotel/Airtel/Jio/Tata in production).
  • The floating panel in the bottom right shows ringing → connected → ended status with a single Hang up button. Pure CSS, no framework.
