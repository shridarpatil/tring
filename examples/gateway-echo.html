pion gateway echo test

WebRTC media gateway check (ADR-001). Click Start, allow the mic, and you should hear your own voice echoed back. With the gateway run against FreeSWITCH (env TRING_FS_SIP_ADDR) the path is the full bridge: browser → pion gateway → FreeSWITCH (echo) → gateway → browser — proving two-way audio through a private FreeSWITCH (milestone 2b). Without FS configured, the gateway echoes locally (milestone 1).
